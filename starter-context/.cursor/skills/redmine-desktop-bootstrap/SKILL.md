# Skill: Bootstrap desktop-клиента Redmine

## Когда использовать
- Новый проект с нуля.
- Нужен минимальный рабочий каркас приложения.

## Цель
Получить запускаемое desktop-приложение под Windows с экраном подключения к Redmine.

## Шаги
1. Создать базовую структуру:
   - `main.js`
   - `preload.js`
   - `renderer/index.html`
   - `renderer/app.js`
   - `renderer/styles.css`
   - `src/redmine/client.js`
   - `src/storage/config-store.js`
2. Настроить Electron окно.
3. Поднять безопасный bridge через preload.
4. Сделать форму подключения:
   - URL
   - API key
   - кнопка "Проверить"
5. Сохранить настройки локально.
6. Восстановить настройки при запуске.

## Критерии готовности
- `npm run dev` запускает приложение.
- Настройки переживают перезапуск.
- Проверка подключения показывает корректный статус.
