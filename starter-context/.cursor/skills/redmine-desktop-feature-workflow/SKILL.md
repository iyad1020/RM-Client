# Skill: Workflow фич (поиск/фильтры/UX)

## Когда использовать
- Добавление фильтров, поиска, сортировки, UX-улучшений.

## Алгоритм
1. Описать пользовательский сценарий (1-2 предложения).
2. Добавить состояние в единый объект `state`.
3. Добавить контролы в UI.
4. Добавить `apply*Filter()` с комбинированной логикой.
5. Сохранить/восстановить фильтры из локального хранилища.
6. Обновить счетчики (`shown/total`) и пустые состояния.
7. Проверить крайние случаи (пусто, регистр, спецсимволы, нет сети).

## UX чеклист
- Фильтры не сбрасываются сами.
- Есть кнопка полного сброса.
- Поиск работает "на лету".
- Причина "пустого списка" понятна пользователю.

## Definition of Done
- Работает вместе с другими фильтрами.
- Сохраняется после перезапуска.
- Есть короткий ручной test plan.
