Где взять URL и API key?

URL Redmine — откройте Redmine в браузере и скопируйте адрес из адресной строки до первого слэша после домена. Пример: https://redmine.company.ru.

API key — в правом верхнем углу нажмите «Моя учётная запись», найдите «Ключ доступа к API» и нажмите «Показать».

Режим ввода времени

Выберите, как удобнее заносить часы. При смене режима все запущенные таймеры автоматически останавливаются — чтобы не всплывал «простой», когда кнопок ▶/■ уже не видно.

В режиме «Таймер» в таблице появляются кнопки ▶ и ■. Пока таймер запущен и вы не трогаете мышь/клавиатуру дольше порога — спросим, что делать с простоем.

Отображение таймера

Только для режима «Таймер» — как показывать бегущее время в строке.

Полная форма трудозатрат

Порядок полей в модалке «Добавить трудозатраты» (из списка записей по задаче). На быстрый ввод из списка задач не влияет.

Тема

Резервные копии

Снапшоты локальной базы (cache.db). Автокопии — каждые 15 минут; также при выходе из приложения.

Файлы и папки

Где на этом компьютере хранятся данные RM Client. При удалении приложения папку данных можно очистить отдельно.

Загрузка путей…

Обучение

Интерактивный тур: список и Agile, быстрый ввод трудозатрат, создание задачи, отчёт, трекер, лента и настройки (включая форму трудозатрат и «Что нового»). Показывается один раз после первой настройки — здесь можно пройти снова.
